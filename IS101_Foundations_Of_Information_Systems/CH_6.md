# Telecommunications, the Internet, and Wireless Technology

## 1. Components of a Computer Network
- A network connects two or more computers.  
- Main components:
  - **Client and Server Computers**: Clients request services, servers provide them.
  - **Network Interfaces (NICs)**: Enable devices to connect to the network.
  - **Connection Medium**: Cables, fiber optics, or wireless.
  - **Network Operating System**: Manages communication.
  - **Hubs, Switches, Routers**: Direct data traffic.
- **Software-Defined Networking (SDN)**: Centralized control of routers and switches through software.

---

## 2. Networks in Large Companies
- Corporations use hundreds of interconnected LANs.  
- Include:
  - Corporate intranet and extranet
  - Web servers and backend systems
  - Mobile wireless networks (Wi-Fi)
  - Videoconferencing and telephone networks
  - Cellular systems for communication

---

## 3. Key Digital Networking Technologies
- **Client/Server Computing**  
  - Distributed model where servers manage resources and clients request them.  
  - Replaced mainframe computing.  
  - Internet is the largest client/server system.
  
- **Packet Switching**  
  - Data split into packets and transmitted independently across the network.  
  - More efficient than older circuit-switched networks.

- **TCP/IP Protocol**  
  - Standard set of communication rules.  
  - Four layers:
    1. Application (end-user apps like web or email)  
    2. Transport (ensures correct delivery, e.g., TCP)  
    3. Internet (addressing and routing, e.g., IP)  
    4. Network Interface (physical transmission)  

---

## 4. Transmission Media
- **Wired**: Twisted pair cables, coaxial, fiber optics.  
- **Wireless**: Satellites, cellular systems, Wi-Fi.  
- **Measures**: Transmission speed (bps), frequency (Hertz), and bandwidth (capacity).

---

## 5. The Internet
- The largest network globally.  
- Access via ISPs with different options:
  - Dial-up: up to 56.6 Kbps  
  - DSL/FIOS: 385 Kbps–40 Mbps  
  - Cable: 1–50 Mbps  
  - Satellite connections  
  - T1/T3 lines: 1.54–45 Mbps  

- **Internet Addressing**:  
  - Every device has an IP address (IPv4 = 32-bit).  
  - **DNS** converts domain names into IP addresses.  
  - Organized into a hierarchical structure (root, top-level, second-level).

---

## 6. Internet Services
- E-mail  
- Instant messaging and chat  
- Newsgroups and forums  
- Telnet (remote access)  
- FTP (file transfer)  
- World Wide Web (main platform for information access)

---

## 7. The World Wide Web
- **HTML**: Language for web pages.  
- **HTTP**: Protocol for transferring pages.  
- **URLs**: Standardized addresses of web resources.  
- **Web Servers**: Manage and deliver content.

---

## 8. Search Engines
- Early models used keyword indexes.  
- Google introduced **PageRank** and later advanced algorithms.  
- **SEO** and **SEM** are used for visibility.  
- 50% of searches now come from mobile devices.

---

## 9. Web 2.0
- Next stage of the web enabling:
  - Interactivity
  - User participation and sharing
  - Real-time control
  - User-generated content (e.g., blogs, wikis, social media)

---

## 10. Wireless Networking and Standards
- **Cellular Standards**:
  - **CDMA**: Used mainly in the U.S.  
  - **GSM**: Used globally.  
- **3G Networks**: 144 Kbps, good for email and browsing.  
- **4G Networks**: Up to 100 Mbps, supports video and rich media.
