
# Foundations of Business Intelligence: Databases and Information Management

## 1. Database Approach to Data Management
- **Database**: A collection of related files containing records about people, places, or things. Before digital databases, businesses used physical file cabinets.
- **Entity**: Represents categories like suppliers, parts, or customers that hold information.
- **Attributes**: Characteristics of entities, such as the name and address of a supplier or the description of a part.

## 2. Relational Databases
- **Relational Databases**: Data is organized into two-dimensional tables, with each table representing an entity.
- **Primary Key**: Uniquely identifies each record in a table (e.g., Supplier_Number for a supplier).
- **Foreign Key**: Links related data across tables, such as linking a part to its supplier.
- **Normalization**: Streamlines data by reducing redundancy and simplifying relationships.

## 3. Data Relationships
- **Entity-Relationship Diagrams (ERD)**: Visual representations of relationships between entities, like the relationship between `SUPPLIER` and `PART`.
- **Types of Relationships**:
  - One-to-one
  - One-to-many
  - Many-to-many (resolved using a join table)

## 4. Database Management Systems (DBMS)
- **DBMS**: Software used to create, store, and manage databases. It separates the logical (user's view) and physical (actual storage) views of data.
- **Operations**: Includes actions like `SELECT` (creating subsets of records), `JOIN` (combining tables), and `PROJECT` (selecting specific columns).
- **Examples**: Microsoft Access, Oracle Database, MySQL.

## 5. Business Intelligence
- **Tools for Business Intelligence**: Used to consolidate, analyze, and provide access to large data sets for improved decision-making.
- **Data Warehouses**: Centralized repositories storing current and historical data.
- **Data Mining**: Uncovers hidden patterns to predict future behaviors, with applications like targeted marketing or identifying profitable customers.

## 6. Multidimensional Data Analysis (OLAP)
- **OLAP**: Supports viewing data from multiple dimensions, such as comparing sales across different regions and time periods.

## 7. Predictive Analytics
- **Predictive Analytics**: Uses data mining techniques and historical data to forecast future behaviors (e.g., customer purchasing patterns).

## 8. Text Mining and Web Mining
- **Text Mining**: Analyzing unstructured data, like text files, to extract valuable information.
- **Web Mining**: Identifies useful patterns from web data (content mining, structure mining, and usage mining).

## 9. Data Warehouses and the Web
- **Web Interfaces**: Allows customers and partners to access data from internal databases using the web, offering both accessibility and savings over legacy systems.
